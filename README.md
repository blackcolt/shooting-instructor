# חידוש רישיון מדריך ירי — מילוי טופס אוטומטי

דף סטטי שממלא את טופס "התחייבות והצהרת מחדש רישיון מדריך ירי" (1.1.2027–31.12.2029) של המשרד לביטחון לאומי ומייצר PDF מוכן להגשה.

- הכול רץ בדפדפן. שום פרט אישי לא נשלח לשרת.
- הפרטים נשמרים ב-localStorage של הדפדפן בלבד, כדי לאפשר חזרה לטופס.
- חתימה: שם מוקלד או חתימה ביד על משטח ציור.

## הרצה מקומית
פשוט לפתוח את `index.html` בדפדפן.
