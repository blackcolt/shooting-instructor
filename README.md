# טפסי מדריך ירי — מילוי אוטומטי

דף סטטי שממלא אוטומטית את טופס "התחייבות והצהרת מחדש רישיון מדריך ירי" (1.1.2027–31.12.2029) ואת "הצהרת הבריאות" לרישוי כלי ירייה, ומייצר PDF מוכן להגשה.

- הכול רץ בדפדפן. שום פרט אישי לא נשלח לשרת.
- הפרטים נשמרים ב-localStorage של הדפדפן בלבד, כדי לאפשר חזרה לטופס.
- חתימה: שם מוקלד או חתימה ביד על משטח ציור.

## הרצה מקומית
פשוט לפתוח את `index.html` בדפדפן.
